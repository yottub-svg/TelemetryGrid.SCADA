# Краткая инструкция оператора

1. В начале смены проверить статус API, время последнего heartbeat и резервного АРМ.
2. При тревоге проверить канал, качество и время события; подтвердить тревогу только после сверки с технологическим процессом.
3. Не изменять пороги и конфигурацию без роли инженера.
4. При отсутствии связи не перезапускать PLC; сообщить L1 и следить за очередью OT-шлюза.
5. При возврате связи убедиться, что накопленные события доставлены без дублей.
6. В конце смены сохранить журнал инцидентов и передать незакрытые тревоги следующей смене.
