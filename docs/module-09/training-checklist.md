# Чек-лист обучения смены

- [ ] Вход и проверка статуса каналов.
- [ ] Поиск `SensorChannel` и просмотр качества.
- [ ] Подтверждение `AlarmEvent` с комментарием.
- [ ] Проверка истории `ShiftTelemetryLog`.
- [ ] Действия при потере heartbeat PLC.
- [ ] Действия при переходе на резервный канал.
- [ ] Возврат на старую консоль без перезапуска PLC.
- [ ] Передача незакрытых тревог следующей смене.

Результат обучения подписывают диспетчер, начальник смены и инструктор подрядчика.
